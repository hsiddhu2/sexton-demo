# sexton-demo

This repository is a deliberate target for [Sexton](https://github.com/hsiddhu2/sexton). Its dependencies are chosen to be unhealthy: dead, deprecated or vulnerable packages, and node-sass with a stylesheet and a script that a migration to sass has to touch. Sexton scans it and opens pull requests here to show its remediation. Nothing in this repository should be installed, built or deployed.
